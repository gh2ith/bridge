# Website QA, 1 November 2026

## Fixes

- Supervisor roster now renders current academic assignments instead of two original HTML rows. The live supervisor has 22 assigned students. Search runs before pagination, and pages contain up to ten records. Report actions retain the selected student.
- All completed roster progress indicators derive their green styling from the same verified state: eight verified weeks and 120 verified hours. Partial progress uses the primary color.
- Company intern directory now renders current placement records and accepted applicants awaiting placement instead of reusing the original application rows. The live company has 41 active interns. A newer ended placement does not retain an older active placement in the directory.
- Progress monitor host-company groups use placement history. A pending application does not establish a host-company relationship.
- Corrected the mobile training summary cascade: desktop columns no longer override the phone layout or compress the certificate into a narrow column.

## Scope limits

This is browser-local frontend verification. It does not certify backend authentication, server storage, actual external notifications, AI matching, or organization-wide synchronization. Public home/sign-in were not redesigned. These checks are a recorded QA pass, not a guarantee against every possible defect or data combination.
