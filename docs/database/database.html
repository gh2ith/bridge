Why the table count changed

The earlier schema kept a separate table for each application’s answers and skills, for each report review, and for several fixed evaluation criteria. The revised schema keeps those values with the application, report or evaluation they describe. Interviews and academic meetings also share the same scheduling tables.

Payments, task submissions, report versions and attendance events still have their own records. Each can happen more than once or needs its own history.
